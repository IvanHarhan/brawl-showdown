# Шоудаун

Браузерная 3D-игра в стиле Brawl Stars, режим «Шоудаун соло». На карте 10 бойцов, свободные места занимают боты, газ сжимает зону, побеждает последний выживший.

**Играть:** https://brawl-showdown.onrender.com (бесплатный сервер засыпает через 15 минут без игроков, первый вход после этого — до минуты).

## Как играть
1. Открой ссылку на игру (на телефоне — горизонтально). Чтобы игра шла на весь экран: Safari → «Поделиться» → «На экран Домой».
2. Введи ник, листай бойцов стрелками, нажми **«Создать комнату»**.
3. Кнопкой **«Поделиться ссылкой»** скинь друзьям ссылку `...?room=ABCD` (например, в Telegram). Друзья могут и сами ввести код.
4. Хост жмёт **«Старт»**: пустые места до 10 займут боты.

**Телефон:** левая половина экрана — стик движения. Красная кнопка — атака: тяни, чтобы прицелиться, отпусти — выстрел; короткий тап — автоприцел. Жёлтая кнопка — супер (заряжается от попаданий), работает так же.
**ПК:** WASD — ходить, мышь — прицел, ЛКМ — атака, ПКМ или пробел — супер.

Ломай ящики и собирай банки: каждая даёт +10% HP и урона. HP восстанавливается, если 3 секунды не стрелять и не получать урон. С 30-й секунды зону сжимает газ.

## Как поменять бойца
- **Характеристики:** `shared/brawlers.ts` — HP, скорость, патроны, перезарядка, урон, дальность, заряд супера. Тип атаки и супера задаётся полем `kind` из готовых вариантов:
  - атаки: `burst` (очередь), `spread` (веер), `bouncer` (табличка через стену);
  - атаки ещё `lob` (бутылка по дуге, лужа на земле); у `burst` можно `bounces` — рикошет от стен;
  - суперы: `base`, `charge`, `invisible`, `jump`, `grab`, `booster` (турель-усилитель), `lob` и `burst`.

  Движок трогать не нужно. После правки пересобери и перезалей сервер и клиент.
- **Внешность:** `blender_tools/characters.json` — рост, комплекция, причёска, одежда, цвета, обувь, аксессуары, оружие. Пересборка моделей:
  ```
  "C:\Program Files (x86)\Steam\steamapps\common\Blender\blender.exe" --background --factory-startup --python blender_tools/build_characters.py
  ```
  Модели появятся в `assets/models/<id>.glb`.
- **Надписи на одежде** (`ШОП`, `GAMAS`): `client/src/render/decals.ts` — текст, цвет и место, модель пересобирать не нужно.
- **Новый боец:** добавь запись в `BRAWLERS` (`shared/brawlers.ts`) и в `characters.json` с тем же `id`, затем пересобери модели.
- **Фразы:** тексты лежат в `tools/voice_lines.json`, генерация — `python tools/gen_voice.py` (Silero, нужен torch). Свои записи клади в `assets/voice/<id>/` с теми же именами (`attack1.ogg`, `super1.ogg`, `death1.ogg`, `win1.ogg`), потом запусти `python tools/gen_voice.py --convert`: он сделает копии `.m4a` для старых iPhone и обновит список фраз.

## Как поменять карту
`maps/showdown1.txt` — обычный текст, по символу на клетку: `#` стена, `B` куст, `X` ящик с банкой, `W` вода, `.` пол, `S` точка спавна (нужно 10). Сохрани файл и перезапусти сервер: клиент получает карту от сервера, пересобирать его не нужно. Новую симметричную карту можно сгенерировать командой `node tools/gen_map.mjs`.

## Запуск локально
```
npm install
npm run dev:server     # сервер на :2567
npm run dev:client     # клиент на :5173, открой http://localhost:5173
```
Поиграть с друзьями с этого ПК без деплоя: `powershell -ExecutionPolicy Bypass -File start-local.ps1`. Скрипт соберёт игру, запустит сервер и откроет публичную ссылку через cloudflared.

## Тесты
```
npm test                                   # юнит-тесты сервера
npm run build; npx playwright test         # e2e: 4 клиента + 6 ботов, пинг 150 мс
$env:BASE_URL="https://<сайт>.netlify.app"; npx playwright test e2e/showdown.spec.ts   # задеплоенная версия
cd server; npx tsx test/sim.ts 5           # 5 каток ботов: длительность, баланс
```
Скриншоты тестов сохраняются в `e2e/screenshots/`.

## Как перезалить
- **Сервер (Render):** `git push` — Render пересоберёт сервер сам (сервис создан из `render.yaml`). Проверка: `https://<сервис>.onrender.com/health`.
- **Клиент (Netlify):**
  ```
  $env:VITE_SERVER_URL="https://<сервис>.onrender.com"; npm run build:client
  npx netlify-cli deploy --prod --dir client/dist
  ```
  Бесплатный Render засыпает через 15 минут без игроков. Первый вход после этого ждёт до минуты, игра показывает «Сервер просыпается…».

## Устройство
- `shared/` — общий код для клиента и сервера: бойцы, константы, карта, физика движения, протокол.
- `server/` — Colyseus. Сервер решает всё сам, 20 тиков в секунду. Логика боя — `src/game/Game.ts`, боты — `src/game/bots.ts`, комната и лобби — `src/rooms/ShowdownRoom.ts`.
- `client/` — Vite + TypeScript + Three.js. Prediction и интерполяция — `world.ts`, бой — `gameView.ts`, рендер — `render/`.
- `assets/` — модели, голоса, иконки и манифест (папка `public` у Vite).

Почему всё сделано именно так — в `DECISIONS.md`.
